    Height from LiDARNo LiDAR match, assumed 4 m

    Esri 3D buildings stream from Esri's buildings scene service. LINZ LiDAR buildings use LINZ NZ Building Outlines, with each height taken as the LINZ DSM minus the DEM inside the footprint; radius and colours apply to these. The shadow probe always uses the LINZ footprints and heights. Keep the DEM elevation model while buildings are on, since the DSM already contains them. Set Range to 5 km or less for crisp building shadows.
